# DeepGA Dental

DeepGA Dental is an experimental deep learning project for dental disease classification from radiographic images. The project explores whether a convolutional neural network architecture generated with **DeepGA** can be improved by adding structured clinical patient data to the visual features extracted from dental X-rays.

The final approach keeps the CNN architecture generated by DeepGA, removes its original trained weights to avoid data leakage, and trains a new multimodal model from scratch using both image features and a clinical feature vector.

> **Main notebook:** `DentalDeepGA_Main_FineT_TArch6ClassCross-NoWeight.ipynb`  
> This is the most important file in the repository because it contains the final training and cross-validation pipeline used to obtain the final model.

---

## Project Goal

The main objective of this project is to improve dental disease classification by combining:

1. **Radiographic image information**, processed by a CNN architecture generated with DeepGA.
2. **Clinical patient data**, encoded as an additional feature vector and fused with the CNN embedding.

The baseline model uses only dental radiographs. The improved model uses both radiographs and clinical metadata, allowing the classifier to use more diagnostic context during training and prediction.

---

## Dataset

The project works with two related datasets:

- A dental radiograph dataset with images organized by disease class.
- A clinical dataset containing useful patient-level diagnostic information linked to the images.

During experimentation, one class was removed because it had too few samples and introduced noise into the training process. The final experiments were therefore performed with **6 classes**.

The final 6-class setup includes:

- Necrosis Pulpar
- Previamente iniciado
- Previamente tratado
- Pulpa Normal
- Pulpitis Irreversible Asintomática
- Pulpitis Irreversible Sintomática

---

## Methodology

The project follows a two-stage approach.

First, DeepGA is used to generate a CNN architecture using the image dataset. This architecture serves as the structural basis for the image feature extractor. However, the trained DeepGA weights are intentionally discarded in the final model to avoid information leakage between the architecture-generation phase and the final multimodal training phase.

Second, a new multimodal model is built. The CNN extracts an image embedding, while the clinical data are encoded into a structured feature vector. Both representations are concatenated and passed into a fully connected classifier. The complete model is then trained from scratch, allowing the CNN and the classifier to learn jointly from the image and clinical information.

---

## Experimental Design

The project includes several experiments:

- Image-only baseline model.
- Image + clinical data multimodal model.
- 5-fold cross-validation for the image-only model.
- 5-fold cross-validation for the multimodal model.
- Clinical-feature combination testing across multiple subsets of clinical variables.
- Individual prediction comparisons between the baseline model and the multimodal model.
- Confusion matrix analysis for both approaches.

The experiments were designed to reduce bias and avoid data leakage. In the final model, the DeepGA-generated architecture is reused, but the weights from the original DeepGA training are not reused.

---

## Main Results

The experiments showed that adding clinical data improved the model performance compared with using images only.

### Hold-out Test Results

| Model | Accuracy | Macro F1 | Weighted F1 |
|---|---:|---:|---:|
| Image-only model | 0.4182 | 0.3676 | 0.3832 |
| Image + clinical data model | 0.61 | 0.57 | 0.60 |

### Cross-Validation Results

| Model | Mean Accuracy | Mean Macro F1 | Mean Weighted F1 |
|---|---:|---:|---:|
| Image-only model | 0.470809 | 0.450213 | 0.470296 |
| Image + clinical data model | 0.603279 | 0.511258 | 0.583274 |

The multimodal model achieved a stronger and more stable performance across folds. The results suggest that clinical variables provide useful diagnostic information that helps the model generalize better than the image-only baseline.

## Best Clinical Feature Combination

An additional experiment evaluated different combinations of clinical variables. The best-performing combinations included variables such as:

- Dx Periapical
- Sensibilidad
- Percusión
- Movilidad
- Palpación

The best reported combination reached approximately:

| Rank | Clinical Feature Combination | Mean Accuracy | Mean Macro F1 | Mean Weighted F1 |
|---:|---|---:|---:|---:|
| 1 | Dx Periapical + Sensibilidad + Percusión + Movilidad + Palpación | 0.623944 | 0.536735 | 0.603202 |
| 2 | Dx Periapical + Sensibilidad + Palpación | 0.624061 | 0.524586 | 0.601280 |

These results suggest that not all clinical variables contribute equally, and that a smaller but well-selected group of variables can provide a better balance between accuracy and generalization.

## Why the No-Weight Approach Was Selected

Several alternative approaches were tested:

- Reusing the trained DeepGA weights.
- Freezing the CNN and training only the classifier.
- Increasing the complexity of the fully connected classifier.
- Using artificial data augmentation.

The final no-weight approach was selected because it reduces the risk of data leakage and allows the full multimodal network to learn from scratch. This makes the evaluation cleaner and more reliable, especially when comparing the image-only baseline against the image + clinical data model.

---

## Limitations

This project is experimental and should not be interpreted as a clinical diagnostic tool. The dataset is relatively small, and some classes have limited representation. The model should be evaluated with larger datasets, external validation sets, and stricter clinical validation before any real-world use.

The reported results are useful for research and academic experimentation, especially for studying how clinical metadata can improve CNN-based dental image classification.

## Future Work

Possible next steps include:

- Training a clinical-data-only model to measure how much predictive signal exists in the clinical variables alone.
- Testing shuffled or mismatched clinical vectors to confirm that the clinical data are genuinely contributing useful information.
- Repeating the process with a standard CNN architecture instead of a DeepGA-generated architecture.
- Expanding the dataset with more images and better class balance.
- Testing additional clinical feature combinations.
- Improving prediction confidence calibration.
- Performing external validation with independent data.
- Exploring safer data augmentation strategies without introducing leakage.
